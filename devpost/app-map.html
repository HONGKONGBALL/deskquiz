堂測 DeskQuiz — where the loop lives

Practice to reuse: when a feature has to be checkable, trace one user action through the request, the function that decides, and the file that remembers it.

  1. public/app.js — make-btn sends POST /api/quizzes.
  2. server.js — createQuiz calls parseFacts and buildQuestions, then stores the quiz.
  3. lib/quiz.js — scoreAttempt runs only on POST /api/quizzes/:id/attempts, so the page does not get the answer key early.
  4. data/store.json — created at runtime and gitignored. That is the memory between restarts.

This map was written by the agent. The learning wrap-up was not done with the learner.
